# PHASE 1D Visual Acceptance Standard

Evidence is required at 1440x1000 desktop and 390x844 mobile viewports for representative Home, auth, Problemset, Problem Detail, Profile/Account, Authoring, Submit, Submission History, and Submission Detail states.

Acceptance requires readable density and statement/source measure, consistent tokens/components, obvious primary actions, stable loading/empty/error/403/404 states, no horizontal overflow at 390px, semantic headings and labels, visible keyboard focus, usable native controls, safe source-as-text rendering, and no fabricated metrics or verdicts. Screenshots and review notes must identify whether data is real, empty, or unavailable.
