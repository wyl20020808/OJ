# Project Status Update Rules

- Every medium or large Goal requires a durable report under `Docs/reports/`.
- Every medium or large Goal requires an update to `Docs/PROJECT_STATUS.md`.
- The report and status update should normally be included in the same scoped commit as the completed Goal.
- High-risk Goals require more detailed evidence and reports.
- PASS, PARTIAL, FAIL, and BLOCKED Goals are all recorded; prior failures are not erased.
- `PROJECT_STATUS.md` is a concise current-state summary, not a replacement for detailed reports.
- Historical reports should generally be immutable. Factual corrections should be additive notes rather than silent rewrites.
