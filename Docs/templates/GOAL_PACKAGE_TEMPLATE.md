## Sizing Guidance

- `SMALL` = maintenance or a narrow correction.
- `MEDIUM` = approximately one focused 45–75 minute Codex work block.
- `HIGH-RISK` = deliberately narrower regardless of duration.

Duration is a sizing heuristic, not a promise or timer.
