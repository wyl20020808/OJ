# Web Judge Elastic Pool UI State Matrix V1

The Judge Machines page shows mode, node counts, pending/active/schedulable capacity, queue waits, utilization, host capacity and autoscaler reason/history when available. Add Node accepts a trusted template and bounded count. Lifecycle controls are disabled with `HOST_AGENT_NOT_AVAILABLE` when unavailable. Loading, forbidden, stale, timeout and mutation pending/failure states remain truthful at desktop, tablet and mobile widths.
