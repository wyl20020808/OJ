## Contract Rules

- A `SUPPORTED` row means the standalone backend contract and focused tests agree; composed runtime still needs Lead evidence where noted.
- `PARTIAL`, `MISSING`, and `BLOCKED_BY_UPSTREAM` must not be hidden by UI defaults or fabricated totals, scores, verdicts, activity, or relationships.
- Problem pagination has a real database count and returns `page.total`; `totalItems` and `totalPages` are not emitted because they are not part of the current shared Web type.
- Guest identity is server-issued and cookie-based. IP is used only as an abuse-limit key and never as identity.
