# Security

OJPlatform is a security-sensitive, pre-implementation project that is intended to execute untrusted user code. It is not currently production-qualified and this repository makes no production security guarantee.

Security design documents live under [`Docs/security/`](Docs/security/), including the [Threat Model](Docs/security/THREAT_MODEL.md), [Trust Boundaries](Docs/security/TRUST_BOUNDARIES.md), [Sandbox Requirements](Docs/security/SANDBOX_SECURITY_REQUIREMENTS.md), [Risk Register](Docs/security/SECURITY_RISK_REGISTER.md), and [Review Checklist](Docs/security/SECURITY_REVIEW_CHECKLIST.md). These documents describe requirements and planned qualification, not completed controls.

Please do not publicly disclose exploitable vulnerability details before maintainers have had a reasonable opportunity to respond. Never put real secrets in examples, issues, or logs. No disclosure email or external reporting channel is established yet; use the repository maintainers' secure project channel when one is formally provided.
